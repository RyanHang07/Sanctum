# Set up Sanctum

The first time Sanctum opens, a short setup walks you through the essentials. Everything it asks can be changed later in **Setup** (Ctrl ,).

## Profiles

A profile is a kind of work: Deep Work, Study, Interview Prep, Light Work. Each one has the apps and links it opens when you enter focus, and a default length. Pick the work types for each profile and Sanctum suggests what to open.

## Distractions

One list, shared by every profile, of what gets sealed: apps, sites, links, and title keywords like "shorts". Common ones (Discord, YouTube, Instagram, TikTok) start on. See [Profiles and distractions](/docs/profiles).

## Your goal

A daily focus goal (120 minutes to start) decides when a day is **kept** for your streak. The idle threshold (3 minutes) decides when the timer pauses because you stepped away.

## Your look

Pick a theme. **Follow Windows** starts on, with Sanctum Dark for dark mode and Sanctum Light for light. See [Themes](/docs/themes).

## Optional

- **The browser extension**, to block sites and tabs. See [The browser extension](/docs/extension).
- **Protection**, a Windows service that blocks sites in every browser and brings Sanctum back if it's closed. See [Protection and tamper](/docs/protection).
- **Google Calendar**, synced both ways with Today and Week. See [Today and Week](/docs/planning).
- **An account and a partner**, who approves early exits. See [Adding a partner](/docs/add-a-partner).
