# Themes

Sanctum comes in thirteen themes: Sanctum Dark and Sanctum Light, GitHub Dark and Light, Dracula, One Dark, Monokai, Tokyo Night, Catppuccin Mocha and Latte, Nord, Gruvbox Dark, and Solarized Light.

## Picking one

Open **Setup › Appearance**. Each theme is a small window in its own colours: hover one to see it across the whole app, click to keep it.

- **Follow Windows** (on to start) uses one theme when Windows is in dark mode and another in light mode. Pick each under "In dark mode" and "In light mode".
- Turn it off to keep one theme whatever Windows is set to.

In **Ctrl K**, "Switch to light" or "Switch to dark" flips it, and typing a theme's name ("Nord") picks it.

## What changes

Colours only: type, spacing, and the mark stay Sanctum's. Each theme brings its own accent for the sealed state and its own colours for the sealed and event backgrounds, and every theme is held to the same contrast standard.

The theme reaches everything: every window, the title bar, the browser extension's pages, and the site when you open it from Sanctum. On a light Windows taskbar, the tray icon is the dark version of the mark.
