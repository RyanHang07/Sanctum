# Themes

Sanctum comes in 75 themes: Sanctum Dark and Sanctum Light, plus dark and light versions of editor themes such as Dracula, Nord, Tokyonight, Catppuccin, Gruvbox, Rose Pine, One Dark, and Solarized.

## Picking one

Open **Setup › Appearance**. Each row shows the theme's name and its two colors: hover or focus one to see a small preview of it, click to keep it.

- **Follow Windows** (on to start) uses one theme when Windows is in dark mode and another in light mode. Only the themes for the mode Windows is in now are listed, under "In dark mode" or "In light mode"; switch Windows to pick the other.
- Turn it off to keep one theme whatever Windows is set to. Then both lists show, **Dark themes** and **Light themes**.

In **Ctrl K**, "Switch to light" or "Switch to dark" flips it, and typing a theme's name ("Nord") picks it. While following Windows, the search finds only the current mode's themes.

## What changes

Colors only: type, spacing, and the mark stay Sanctum's. Each theme brings an accent, used for the sealed state and the main buttons, and a second color, used only for marks like kept days and the goal tick. Every theme is held to the same contrast standard in light and dark.

The theme reaches everything: every window, the title bar, the browser extension's pages, and the site when you open it from Sanctum. On a light Windows taskbar, the tray icon is the dark version of the mark.
