# Keyboard shortcuts

| Keys | Does |
|---|---|
| Ctrl Enter | Enter focus |
| Ctrl K | Search or command: jump anywhere, add a task, flag a distraction, start focus, change the theme |
| Ctrl 1 | Today |
| Ctrl 2 | Week |
| Ctrl 3 | Stats |
| Ctrl 4 | Trackers |
| Ctrl 5 | Notes |
| Ctrl 6 | Journal |
| Ctrl , | Setup |
| Ctrl M | Compact timer (while sealed) |
| Ctrl B | Collapse the sidebar |
| Alt ↑ / Alt ↓ | Move a block in a note, or an item in a list |
