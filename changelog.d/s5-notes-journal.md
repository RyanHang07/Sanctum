- **The journal's day strip says how each day went.** Under each date, a kept day has a small dot in the theme's second colour, a missed day a hollow ring, and today the accent, the same marks as Week. A page you wrote gets a small neutral dot beside it instead of the accent. The key (Kept, Missed, Today) appears beside the strip only while you hover it or tab into it, and each day's name reads its state out for screen readers ("Sunday, November 15: kept, page written"). The weekday letters are no longer forced to capitals.
- **"1 session", not "1 sessions".** The journal's day card counts sessions in the singular when there is one.
- **The journal's headlines are plain sentences.** "The journal is locked.", "A page a day, yours alone." and, in place of the old question, "Choose what a page asks.", all from `headlines.ts`.
- **The journal's prompt themes are a segmented control,** a tablist with arrow keys like the rest of the app, instead of underlined tabs.
- **The note toolbar draws its tools as icons.** Lists, checklists, tables, images and callouts, and a table's row and column tools, are line icons instead of text glyphs. Bold, italic, strikethrough, the headings and numbered lists stay letters, and italic is no longer set in a serif.
- **Notes read more clearly.** Edited times, the search placeholder and the drag handle use muted text instead of faint, the search box has the 3:1 input edge, the title is set in Schibsted Grotesk, a pinned note's pin is neutral rather than the accent, and deleting a note is a bin icon. "Link works for" in the share menu is a sentence-case label.
- **Focus shows on every notes and journal field.** The note title and search box draw the shared focus ring on their row, and the journal's PIN fields use the shared ring instead of an accent border.
